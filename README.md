# BOGEN

**B**aukasten für **O**ffline-Formulare: **G**estalten, **E**intragen, **N**achrichten teilen. BOGEN ist eine statische Offline-Web-App (PWA); alle Daten bleiben auf deinem Gerät.

Die App: <https://olivermue.github.io/bogen/>

## Mitmachen

Dieses Repository ist ein Schaufenster. **Pull Requests werden nicht angenommen.**
Vorschläge (z. B. neue Formulare für die Bibliothek) bitte als Issue einreichen und die `.json`-Datei des Formulars anhängen.

## English

BOGEN is a static offline web app (PWA) for filling in and building forms. All data stays on your device.

App: <https://olivermue.github.io/bogen/>
